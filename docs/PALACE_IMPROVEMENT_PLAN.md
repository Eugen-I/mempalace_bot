# 🏰 План комплексного улучшения MemPalace в Telegram-боте

Данный документ содержит утверждённый архитектурный план и пошаговую стратегию модернизации Дворца памяти (MemPalace), работы с заметками, базы данных, навигации, поиска и интеграции ИИ (агента и RAG).

---

## 1. Архитектурный срез и зоны роста

1. **Разрозненность заметок и Дворца:**
   - 4 изолированных хранилища: Apple Notes, MemPalace Drawers (ChromaDB), быстрые заметки (`my_notes/`, `insights/`, `research/`), личные заметки (`handlers/personal_note.py`).
   - Отсутствие обратных ссылок (backlinks): ящик в ChromaDB не знает UUID исходной заметки Apple Notes.
   - Искусственная изоляция агента: в `handlers/notes_agent.py` прописан запрет доступа к Дворцу.

2. **База данных и стабильность:**
   - 6 независимых баз SQLite в разных каталогах (`~/.mempalace/`, `~/Documents/mempalace/`, `mempalace_bot/`).
   - Временные маппинги кнопок навигации живут в in-memory `TtlDict` (`_room_callback_map`, `_wing_callback_map` в `navigation.py`). При перезапуске бота кнопки сообщений устаревают («Сессия истекла»).
   - Необходим централизованный менеджер подключений с гарантированным WAL, `busy_timeout` и потокобезопасностью (`check_same_thread=False`).

3. **Навигация по Дворцу (Telegram UI):**
   - Лимит пагинации (5 элементов) замедляет просмотр сотен комнат и ящиков.
   - Нет «хлебных крошек» (`Дворец > Крыло > Комната > Ящик`).
   - Нет быстрого поиска комнат по тексту прямо в меню навигации.

4. **Интеллектуальный поиск (OmniSearch):**
   - Команда `/search` ищет только во Дворце (`chroma.sqlite3`).
   - Поиск по Apple Notes и локальным файлам изолирован.
   - Отсутствует сквозной гибридный поиск (BM25 + Vector) с Reciprocal Rank Fusion (RRF) по всем источникам.

5. **Взаимодействие с ИИ:**
   - **RAG 2.0:** Необходим этап Query Rewriting / Expansion перед поиском во Дворце, чтобы исключить потерю контекста при разговорных запросах.
   - **Агент ИИ:** Расширение палитры инструментов (самостоятельное создание туннелей, запись фактов в KG, наведение порядка в комнатах) и поддержка внешних LLM провайдеров (Gemini, OpenAI) наряду с локальным Qwen в `agent_engine.py`.
