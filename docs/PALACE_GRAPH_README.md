# Граф знаний «Дворец памяти — Созвездия» (Palace Knowledge Graph)

Автономная интерактивная визуализация чертогов памяти и семантических связей (туннелей) между комнатами и заметками.

---

## 1. Как открыть

1. **Двойным кликом в браузере (Chrome / Safari / Firefox):**
   - Откройте файл `palace-graph.html` прямо из Finder или терминала:
     ```bash
     open palace-graph.html
     ```
   - Работает локально по протоколу `file://`, без веб-серверов, без интернета и без CDN.

2. **Из Telegram-бота MemPalace:**
   - В меню Дворца (`/palace`) нажмите **«🗺️ Скачать карту (.html)»**.
   - Бот пришлёт файл и кнопку **«🖥️ Открыть в браузере (Chrome / Safari)»** — по нажатию на кнопку граф мгновенно откроется в вашем браузере на Mac!

3. **В Telegram WebView:**
   - Полностью адаптирован под мобильные устройства и тему оформления Telegram (iOS / Android).

---

## 2. Как обновить данные

Для пересчёта графа, извлечения ключевых сущностей (TF-IDF) и обновления межкрыльевых туннелей выполните:

```bash
# Автоматическое чтение из локального хранилища ChromaDB (~/.mempalace/palace):
python build_graph.py

# Либо с явным указанием пути к экспорту:
python build_graph.py --input path/to/drawers_export.json
```

Скрипт автоматически:
- Проанализирует все тексты 2766+ ящиков;
- Рассчитает ключевые термины по комнатам;
- Найдёт межкрыльевые ассоциации и обновит `tunnels.json` и `palace_graph_data.json`;
- Обновит файл `palace-graph.html`.

## 3. Какие 3 константы менять для настройки вида

Все визуальные параметры находятся в блоке `<script>` файла `palace-graph.html`:

1. **`CELL_SIZE = 64;`** (строка ~470)
   - Размер ячейки пространственной хэш-сетки для проверки попадания курсора (hover/click).
   - Если узлы слишком плотные или сложно попадать пальцем на мобильных — увеличьте до `80` или `96`.

2. **`const targetDist = l.type === 'tunnel' ? 140 : 55;`** (строка ~520)
   - Длина пружин графа (расстояние связей).
   - `55` — расстояние от крыла до комнат.
   - `140` — длина межкрыльевых туннелей. Увеличьте (например, до `200`), чтобы крылья разошлись дальше друг от друга.

3. **`charge = -180;`** (строка ~538)
   - Сила электростатического отталкивания узлов друг от друга.
   - При `-250` граф станет более просторным и разреженным; при `-120` узлы сгруппируются плотнее.

## 4. Интерактивные возможности

- **Слой B «Созвездия»:** force-directed симуляция на Canvas 2D, физика стабилизируется за 300 тиков и засыпает для экономии батареи (60 FPS).
- **Слой A «Атлас»:** круговая Sunburst-миникарта в левом нижнем углу с подсветкой и клик-навигацией.
- **Раскрытие ящиков и заметок:** кликните на комнату и нажмите **«🌐 Раскрыть ящики»** — вокруг комнаты по орбите раскроются спутники-ящики, а в панели инспектора откроется прокручиваемый список заметок с названиями, датами и превью.
- **LOD (Level of Detail):**
  - При отдалении ($k < 0.45$) видны только крупные крылья.
  - При среднем зуме ($1.1 \le k < 2.4$) появляются подписи комнат с защитой от наложения (де-клаттеринг).
  - При приближении ($k \ge 2.4$) внутри комнат проявляется россыпь ящиков по спирали Фибоначчи.
- **Поиск:** строка поиска с авто-фокусом и подсветкой.
- **Забытое (`⏳`):** подсветка комнат без обновлений более 30 дней.
- **Экспорт PNG (`📷`):** сохранение красивого скриншота графа.
